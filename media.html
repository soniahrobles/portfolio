Sun Lamp Product Development

Description

Designed and fabricated a functional lighting piece inspired by existing designs, incorporating a personal sun motif and demonstrating advanced 3D modeling, fabrication, and assembly techniques.


Task List

Developed concept with a personalized sun-ray design aesthetic.

Modeled all components in Fusion 360 with precise dimensional planning.

Engineered structure around a plug-in pendant light cord ensuring functionality and wall mounting.

Designed for light diffusion through an open dome and spacing considerations.

Adjusted components to fit socket, retaining ring, and electrical elements.

Adapted design for 3D printing by segmenting parts for size constraints.

Assembled components using adhesive and press-fit techniques.

Applied finishing processes including metallic paint and gloss coating for durability and appearance.

Completed full assembly and tested functionality through installation and use.

Description

Using AI-assisted coding and concepts from instructor-led projects, the program combines storytelling, user interaction, and visual design to create a calm, immersive environment where users explore tea origins, read book excerpts, and customize their own drink.


Task List

Designed a linear, interactive narrative with light branching to guide user exploration.

Built a virtual tea shop environment featuring interactive elements such as tea jars and books.

Programmed hover-based interactions to reveal ingredient details and book excerpts.

Developed a user journey including entering the shop, exploring, and completing a drink-making experience.

Integrated storytelling elements connecting tea ingredients to cultural and geographic origins.

Created step-by-step interaction flow for drink customization.

Designed visual and emotional tone using warm, calming aesthetics and ambient elements.

Structured storyboard and user flow from entrance to final reading nook experience.

Utilized AI tools to assist in coding logic and implementation alongside foundational programming skills.

Combined multiple smaller coding concepts into a cohesive, fully functional interactive project.
